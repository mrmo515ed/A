Anime Black — Icon Pack
========================
Concept: neon violet/cyan anime eye on a black-purple background.

Files:
- anime-black-icon-1024.png: square master for store listings / design handoff
- anime-black-icon-round-1024.png: circular preview
- ic_launcher_<density>.png: legacy square Android launcher sizes
- ic_launcher_round_<density>.png: circular Android launcher sizes
- anime-black-icon-source-1254.png: original generated artwork

Important:
- This pack is a visual asset pack. It has NOT yet been installed into the Android repository or APK.
- The Android project already has adaptive launcher resources under app/src/main/res/mipmap-anydpi-v26 and drawable; the developer should replace/update those resources and rebuild/test the APK.
- For a production adaptive icon, use foreground/background layers rather than a pre-rounded PNG so Android can apply device-specific masks.
